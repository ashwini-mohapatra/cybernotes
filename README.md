## Obsidian Hotkeys 

 "##" -> For Heading
Ctrl+B -> Bold
Ctrl+I -> Italics
"~~ ~~ " -> To Strike Off
"== == " -> For Highlight
"> " -> Quote Block
"- " -> Bullet List
"Numbers(1,2,3,4,5,6,7,8,9,0)" -> Numbered List
"-[] " -> Checklist
"--- " -> On a empty Line creates Divider
" '` ` " -> Inline code (backtick)
" ```' ``` " -> Code Block (3 Backticks)
[[]] -> Link to Another Note
[Text]"( Link)" -> For Eternal Link

Ctrl <- -> For Forward Backward Movement in Notes rather than using mouse
Ctrl F -> Find 
Ctrl T -> New Tab
Ctrl W -> Close Current Tab
![[]] -> To Embed Entire Note in the link to another note
![]"()" -> Will Show Image if the external link contains image
Ctrl P -> Shows Command Palette 
Ctrl O -> Find and open a note the fast way
"#" -> Add tags to notes to help track them like hashtags 
Image, PDF, Audio, Video can be attached by Drag & Drop
